# Symbols Nerd Font Mono attribution

Hirte bundles the unmodified `SymbolsNerdFontMono-Regular.ttf` from Ghostty's
pinned `NerdFontsSymbolsOnly-3.4.0.tar.gz`:
https://deps.files.ghostty.org/NerdFontsSymbolsOnly-3.4.0.tar.gz

- Archive SHA-256: `1164d1b956d4bde248d7b2f0998c43cc94f5202431a1564a793895b1e73b0d04`
- Font SHA-256: `f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60`
- The archive's MIT `LICENSE` is preserved at
  `hirte/Fonts/SymbolsNerdFont-LICENSE.txt`.

`LICENSE`, `license-audit.md` and the component notices under `src/glyphs/` are
unmodified copies from Nerd Fonts v3.4.0, commit
`fa7b859994228a9c8759f99c55a8d31ee92a1b5e`:
https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0
Their relative paths match that source tree. The audit is upstream documentation;
it also covers fonts that Hirte does not bundle.

The Symbols Only font combines glyphs from the sources listed in that audit:
Codicons, Devicons, Font Awesome, Font Awesome Extension, Font Logos, IEC Power
Symbols, Material Design Icons, Seti-UI / original source, Octicons, Pomicons,
Powerline Extra Symbols, Powerline Symbols and Weather Icons. The font's MIT
notice does not replace the individual component notices preserved here. These
are upstream glyphs combined into the Symbols Only font, not new icon designs
by Hirte. See the pinned audit and notices for the component-specific terms.

`scripts/licenses.py` includes this provenance, the archive's MIT notice, the
upstream root license, audit and all eight component notices in the in-app
Open-Source Licenses entry.
