# Hirte agent icons

The Claude, Codex, Grok and Gemini SVG assets were copied from the authorized
desktop herdr app's agent icon assets. Their original shapes and viewBox are
preserved; width and height were normalized from `1em` to `24` for asset
compilation. The source tree attributes agent icons to LobeHub icons (MIT) and
the agents' own marks. LobeHub's notice is included with Hirte's in-app
attribution: https://github.com/lobehub/lobe-icons

The source tree's `LICENSES.md`, `LICENSE-LobeHub.txt` and `LICENSE-Lucide.txt`
are retained unchanged. Lucide's notice concerns the desktop app's generic UI
glyphs; it is not a claim that these four agent marks are Lucide designs.
